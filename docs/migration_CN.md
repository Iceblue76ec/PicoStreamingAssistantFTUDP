## 冲突处理与实现边界

- 异步接收保留。绑定即成功，后台解析长度/类型检查后的权重前缀，不恢复旧同步 Update 收包循环。
- 最新样本槽替代历史队列；消费者复制整帧后映射，避免 Span 指向后台正在覆写的数组。
- 接收 Task 的终止由内部异常传递，1 秒后重建；处理异常保持连接。服务/配置/绑定失败退避 5 秒。
- IPicoConnector 公共签名保持不变。测试使用内部时钟、端口及接收操作注入，生产端口仍为 29765。
- 日志共享去重状态并串行更新诊断。无数据时由消费者定期检查，不依赖报文到达。
- CSV 保留 Channel，容量 1、满时替换旧样本；不恢复旧 Logger.cs，不启用默认 CSV。
- 不实现 hybrid 映射，不改变上游 Ignore 状态；不实现分片重组。

## 自动验证

在 macOS 使用 .NET SDK 10.0.401，按仓库固定依赖构建 .NET 10 模块。
Debug 完整测试及 Release 完整测试通过；默认关闭 CSV 与定义 `FILE_LOG` 的 Release 模块均构建成功。
使用 `ContinuousIntegrationBuild=true` 跳过安装目录复制，仅在测试中绑定随机本地 UDP 端口。

完整测试：73 项通过、1 项跳过、0 项失败。跳过项为上游 hybrid 待实现测试。
验证内容包括：

- 无首包绑定、端口占用、首次收包前关闭、故障后关闭、重复关闭及端口复用。
- 0/3/311/312/908 字节及额外后缀，错误类型、尾部缺省、最新有效样本不被后续错误包清除。
- 空闲等待、新样本/关闭通知、后台故障传递及详情先于恢复提示、整帧快照、1024 包批次发布及取消、已处理超时。
- 可控时钟验证 1/5 秒边界、失败结束后计时、成功清除窗口、处理故障保留连接及清理失败继续恢复。
- 日志重复汇总、非面捕类型固定签名、模板分组、时间/级别、暂停计时及并发计数。
- CSV 慢写时投递不阻塞、只保留最新待写样本、关闭刷新及创建文件/写入行失败隔离。
